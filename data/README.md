This folder contains sample ecological, biodiversity, infrastructure, and satellite-derived datasets used by COEXIST for environmental analysis and geospatial intelligence workflows.

## Dataset Categories

### Forest Cover
- NDVI vegetation layers
- satellite-derived forest density maps

### Wildlife Data
- biodiversity observations
- elephant hotspots
- wildlife corridor approximations

### Infrastructure Data
- roads
- railways
- urban infrastructure layers

### Forest Loss & Encroachment
- forest degradation alerts
- historical forest loss data
- ecological disturbance indicators

## Formats Used
- GeoJSON
- GeoTIFF
- GIS vector layers
- raster datasets

The datasets are used for:
- ecological overlap analysis
- habitat fragmentation detection
- AI-based ecological risk scoring
- infrastructure impact simulation
