# COEXIST
COEXIST is an AI-powered ecological urban planning system that helps cities grow sustainably while protecting wildlife habitats. Using satellite data, geospatial analysis, and machine learning, it detects habitat encroachment, predicts ecological risks, and supports smarter, biodiversity-friendly urban development.
# problem statement 
wildlife habitats are shrinking because of urban expansion
Modern urban expansion often:
  fragments wildlife habitats
  blocks migration corridors
  increases human-animal conflict
  damages biodiversity and ecosystems

Current environmental planning systems are:
  slow
  reactive
  expensive
  heavily manual
  difficult to scale

COEXIST introduces AI-assisted ecological planning to improve sustainable infrastructure development.

# how it works 
1. Data Collection
  The system gathers:
    satellite imagery
    forest cover data
    wildlife observations
    road and railway infrastructure
    terrain and environmental data

2. Geospatial Processing
  GIS layers are processed using:
    GeoPandas
    Rasterio
    Google Earth Engine
    OpenStreetMap data

3. AI Simulation & Risk Analysis
  COEXIST evaluates:
    habitat fragmentation
    wildlife disruption probability
    ecological sensitivity
    infrastructure impact

4. Recommendation Engine
  The platform suggests:
    safer construction routes
    wildlife crossings
    ecological buffer zones
    mitigation strategies
